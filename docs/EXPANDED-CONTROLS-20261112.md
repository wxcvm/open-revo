# 本机扩展控制验收 — 2026-11-12

## 范围

本轮针对 P916F-STX / BIOS 1.15 / Ryzen AI 9 H 365 / Radeon 880M。
保留多机型驱动，不完整合并上游，不依赖原厂控制中心。
DeepSeek Harness 负责 CPU、ADLX 图形控制、界面测试、PMC2 充电协议初稿与交叉审查；主代理集成、修正 ABI 和事务问题，并执行本机验收。

## CPU

电源管理页新增 Windows CPU 电源策略，AC/DC 分开调节最大处理器状态、性能提升模式和 Windows 最大频率策略。
这些是 OS 策略，不是 SMU TDP、核心电压或实际时钟保证。
写入绑定已捕获的活动计划 GUID；同一计划重新激活后回读；保留可读取的独立能源叠加。
失败时条件回滚，遇到外部计划变化不切换回旧计划。

实际本机验收：电池最大处理器状态 100% -> 99% -> 100%，保存值回读一致、活动计划和能源叠加未变化。
未做硅片频率、性能增益或功耗上限测量。

## GPU

显示设置页新增 AMD 驱动图形特性：Anti-Lag、Chill、图像锐化、FRTC。
Chill 范围由驱动读取（本机 30–300 FPS），FRTC 范围由驱动读取（本机 15–1000 FPS）。
本机驱动要求先启用 FRTC 再改目标 FPS；界面与 IPC 均检查前置状态。
Anti-Lag / Chill 互斥前置条件必须可读且确认；恢复按反向顺序、仅在仍持有写入值时进行。
核心/显存/功率/风扇手动调校能力在本机驱动中均返回不支持，不伪造超频控件。

实际本机验收：
- ADLX 1.5.0.124；官方头文件 C++ 独立探针与 Rust 支持度回读一致。
- 锐化 false -> true -> false，Chill 和其余字段不变。
- Chill 60/60 -> 59/61 -> 60/60；FRTC 开启后 60 -> 61 -> 60；Anti-Lag / Chill 互斥切换恢复原状态。
- 首轮强锐化测试抓到函数表 slot 错误导致测试进程访问异常；已拆分真实锐化接口，修正 setter 至 slot 7，回归测试及实机复测通过。旧异常日志保留，不作为通过证据。
- ADLX 所在线程负责初始化、串行调用、释放接口和终止；真实 shutdown 测试通过。
- 温度、核心频率、显存频率均有 ADLX 实读值；监控心跳只取同名适配器且五秒内的新缓存，不阻塞等待驱动，不借用 CPU 温度。

以上验证为驱动设置/遥测，不代表游戏帧率收益或所有游戏兼容性验收。

## 独立限充协议来源与本机验证

新发现的原始研究：[P916F-STX battery charge-limit protocol](https://github.com/YMGPwcca/Mechrevo-Xingyao-14/blob/main/docs/battery-charge-limit.md)、[threshold semantics](https://github.com/YMGPwcca/Mechrevo-Xingyao-14/blob/main/docs/battery-threshold-semantics.md)。
相关文档仅作为协议研究来源，未整体导入仓库；现有其他平台的 EC 地址不适用于该协议。

本机已安装并运行 inpoutx64；本轮只打开既有设备，不安装、启动、替换或下载驱动。
新增控制需要这个端口访问通道，故“独立”指不需要原厂应用/服务，并非不需要内核端口访问能力。
仅匹配本机 DMI 与 BIOS 1.15；未知机器/版本不试写。锁、超时、残留输出检测和独立回读均在 HAL。

独立 C# 探针实测：关闭 0/0/0 -> 开启 1/80/100，约 30 秒多次回读一致 -> 关闭 0/0/0。
T1/T2 setter 回显分别为 80/100，enable/reset 未观察到输出字节；reset 清除阈值的行为在本机已实测。
正式 Rust 路径再次实测通过：使用生产 IPC 相同的真实 DMI/BIOS 检查，0/0/0 -> 1/80/100 -> 0/0/0，三秒后回读仍一致。
默认纯测试不接触硬件；实机测试保留为显式忽略测试，不允许伪造匹配身份来绕过机型检查。
本机 BIOSVersion 为 1.15，匹配资料基线。未做重启、睡眠、深度断电或完整充电周期验收。

T1 是停止充电边界，不应把 T2 解释成普通的恢复充电下限。原始研究的 T2<100 会触发 AC 在线主动放电。
本面板按普通充电上限用途固定 T2=100，提供工作站 60%、电池长效 80% 和自定义 1–99%。
满充通过关闭限充实现，不使用行为未定的 T1==T2。
60% 与任意自定义值的长期充电行为未逐一测试；显示的是协议回读确认，不标为完整物理行为验证。
不在启动时自动改写充电设置。测试结束恢复用户原来的关闭状态。
