# OpenRevo Windows 管理中心

从大面板顶部打开 **管理中心**。独立窗口只加载内置页面，不依赖原厂控制中心；托盘启动不运行新的磁盘扫描。

| 页面 | 能力和数据口径 |
| --- | --- |
| 电脑体检 | Windows 可用物理内存、卷容量、安全中心状态和 WUA 已安装历史；历史并非在线更新检查。 |
| 资源去向 | 复用实测计数器与可选历史；按已辨认的同一可执行文件路径分组。只分别相加私有驻留或私有提交，读数缺失时标为部分。普通应用可请求正常关闭，PID 与创建时间须匹配；仍在运行时不报结束。 |
| 存储与清理 | 限所选的本地卷或目录，区分逻辑大小、已知占盘和未扫描差额；跳过云占位、重解析点，硬链接不重复计入。大文件可定位；重复检查仅在同大小且至少 1 MiB 的文件中校验完整 SHA-256，最多收集 24,000 个候选、读取 4 GiB；限额有标记。 |
| 可回收项目 | 当前用户超过七天未修改的临时文件类型，以及已退出的 Edge、Chrome、Brave 已知缓存。每批至多 200 项，逐项预览，执行前复核。Windows Shell RecycleItem 不走永久删除；回收不等于释放容量。 |
| 启动项 | 当前用户 Run 和 .lnk 可禁用和恢复；写入前保留原值，注册表使用事务，快捷方式仅同卷移动且不覆盖。计划任务、服务和全局、一次性项目只读。 |
| 软件管理 | Win32 安装记录和当前用户 MSIX 应用。卸载交由 Windows 设置，不执行登记的卸载命令。 |
| 故障时间线 | Display、应用错误和无响应、系统错误检查、异常重启、意外关机和更新事件，按时间对照已有资源峰值；时间重合不是根因判定。 |

扫描结果仅存在运行内存，最近 50 次维护回执留在本机，自启备份独立保留；资源历史仍需显式开启。管理接口不接入插件桥，不修改硬件、网络、刷新率或 ARTEX 保活行为。

浏览器回归命令：node tools/manager-ui.test.cjs（沿用仓库测试的 Playwright 依赖）。原生测试筛选 system::manager；交互式 Windows 上可单独运行忽略的 manager_live_read_windows_providers 与 manager_live_recycle_transfer。后者只将单个临时夹具移入 Windows 回收站。
