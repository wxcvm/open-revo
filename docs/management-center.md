# OpenRevo Windows 管理中心

普通方式启动 OpenRevo 会直接进入 **标准权限管理中心**。该模式不初始化硬件驱动、不恢复固件或显示设置、不加载第三方插件；仍可使用体检、资源统计、维护和定时熄屏保活。关窗可回托盘，带 --minimized 的普通权限启动不打开面板或启动扫描。

硬件调校保留在管理员会话。管理中心所有页面顶部都有“打开硬件面板”；只有点按钮才交给 Windows 显示管理员确认。取消或新进程未确认就绪时留在管理中心；新进程验证同一桌面账户和原应用身份、确认就绪后，当前标准权限进程才退出。退出会释放本次保活，扫描或维护进行时暂停切换。已在硬件会话中时，顶部按钮直接返回原面板。应用不创建、自修复或接管管理员登录任务；旧版任务带 --minimized 启动新程序时会在硬件初始化之前退出。

| 页面 | 能力和数据口径 |
| --- | --- |
| 电脑体检 | Windows 可用物理内存、卷容量、安全中心状态和 WUA 已安装历史；历史并非在线更新检查。 |
| 本机快捷控制 | 面板内直接读取、设定并回读默认播放设备的音量和静音。标准权限会话中也可选择 Windows 能源模式；未知模式不覆盖，已有硬件电源联动仍由硬件面板管理。Windows 更新、防护与软件卸载入口仍明确交给 Windows。 |
| 资源去向 | 复用实测计数器与可选历史；按已辨认的同一可执行文件路径分组。只分别相加私有驻留或私有提交，读数缺失时标为部分。普通应用可请求正常关闭，PID 与创建时间须匹配；仍在运行时不报结束。 |
| 存储与清理 | 限所选的本地卷或目录，区分逻辑大小、已知占盘和未扫描差额；跳过云占位、重解析点，硬链接不重复计入。整卷可单独对账系统已用、按可读路径分类的分配量和未对账占用。大文件可定位；重复内容校验需选择开启，仅在同大小且至少 1 MiB 的文件中校验完整 SHA-256，最多收集 24,000 个候选、读取 4 GiB；限额有标记。 |
| 可回收项目 | 当前用户超过七天未修改的临时文件类型，以及已退出的 Edge、Chrome、Brave 已知缓存。每批至多 200 项，逐项预览，执行前复核。Windows Shell RecycleItem 不走永久删除；回收不等于释放容量。 |
| 启动项 | 当前用户 Run 和 .lnk 可禁用和恢复；写入前保留原值，注册表使用事务，快捷方式仅同卷移动且不覆盖。计划任务、服务和全局、一次性项目只读。 |
| 软件管理 | Win32 安装记录和当前用户 MSIX 应用。卸载交由 Windows 设置，不执行登记的卸载命令。 |
| 故障时间线 | Display、应用错误和无响应、系统错误检查、异常重启、意外关机和更新事件，按时间对照已有资源峰值；时间重合不是根因判定。 |

扫描明细只在运行内存中。整卷显示 Windows 实际容量与分配字节，不混用用户配额与整卷数据。总容量与已用、可用之和有余差时单列，并显示 Windows 报告的保留或池不可用空间，不重复相加。多目录硬链接单独归类且计一次，回收站的 Windows Shell 总量单独显示、不参与分配量加总。未对账占用只从系统已用中计算，包含不可读项目与文件系统元数据，不视作可释放空间。卷级与路径测量不吻合时不算差额。

只有点击“保存本次卷快照”才写入本机历史；按 Windows 卷标识比较，同一个盘符换卷后不沿用旧记录。每卷最多 12 条、合计最多 72 条，只存时间、容量和分类汇总，不存文件或目录名称。最近 50 次维护回执、自启备份、资源历史仍各自独立。

标准权限也能手动申请熄屏保活；主动睡眠和退出释放该请求，不自动恢复。管理接口不接入插件桥，也不改动风扇、网络或刷新率。

浏览器回归命令：node tools/manager-ui.test.cjs（沿用仓库测试的 Playwright 依赖）。原生测试筛选 system::manager；交互式 Windows 上可单独运行忽略的 manager_live_read_windows_providers 与 manager_live_recycle_transfer。后者只将单个临时夹具移入 Windows 回收站。
