# 资源去向

入口：**系统监控 → 资源去向**。这部分只读 Windows 统计，不要求原厂控制中心，也不修改风扇、电源或显卡设置。原有监控概览、卷容量和硬件性能记录保留。

| 页面 | 数据口径 |
| --- | --- |
| 内存 | 安装容量来自 SMBIOS，Windows 可见和系统提交量来自 PSAPI。可用量可对账时才拆出待机、空闲/零页；待机并非丢失的容量。按进程的 `PrivateWorkingSetSize`（物理驻留）和私有提交是两列；不拿工作集总量或私有提交替代驻留。内核页、缓存、未读到的页面等可造成已用和可见进程之和不相等；重叠的诊断统计不能叠加。 |
| CPU | 全机利用率为 PDH；进程按 `GetProcessTimes` 两次差分，以全机逻辑处理器为 100%。趋势键含 PID 和创建时间，PID 复用不沿用旧曲线。 |
| 磁盘 | Windows `PhysicalDisk` 实例及其总量：读写字节率和读写操作率。不是卷容量或按进程 I/O。 |
| 网络 | Windows `GetIfTable2` 接口字节计数差分，以硬件网卡做物理汇总；虚拟接口独立。不获取包、连接或端点。 |

实时约每 2 秒采样，最近 10 分钟存在运行内存中，可选择进程、磁盘或接口；悬停或用图下滑杆定位实际采样时间。切回页面查看仍在窗口内的旧样本，离开期间和计数器重新预热时不补线。早于 Windows 10/11 22H2 2023 年 9 月更新的系统可能不支持私有驻留读数，显示为未取得。

可选的七天历史**默认关闭**。开启后按 UTC 日期归档到 OpenRevo 本地应用数据；按分钟保存系统总量的加权平均、采样峰值和有效覆盖毫秒，不保存进程、设备名称或路径。离开页面或退到托盘时约每 10 秒只采总量，不枚举进程或读取显卡。锁屏/休眠暂停，退出后停止。图表可查 1 小时、24 小时或 7 天；CSV 保留每分钟明细，缺失值为空，覆盖为零。不满一分钟的覆盖不会补齐。关闭保留已有记录，「清除汇总」只删除 OpenRevo 自己的历史文件。
